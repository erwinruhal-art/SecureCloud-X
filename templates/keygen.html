Technical Implementation Details

Entropy Source: The primary seed is gathered strictly from the operating system's cryptographic entropy source (os.urandom(32)). Supplementary inputs (monotonic nanosecond clock drift, process identifier) are mixed during state initialization and reseed operations to ensure independence across process forks.

State Architecture: The generator maintains internal state (K, V) where K is a 32-byte HMAC key and V is a 32-byte working value. Each generate request produces pseudorandom bits through iterative HMAC-SHA256 calculations followed by an immediate state update.

Key Separation: Keys produced by ASKG are used exclusively for symmetric payload encryption (ChaCha20-Poly1305). Post-quantum encapsulation is performed using ML-KEM-768, and the session key is wrapped using HKDF-SHA256.
